В обновлении теперь поддерживаются два формата написания эффектов: 
1. Короткий
2. Полный

Вы можете свободно комбинировать их внутри секции effects.

!!! ПРИМЕР !!!

actions:
  - trigger: on_hit
    chance: 100.0
    effects: # cast секции больше нету, только effects!
      # 1. Используем короткий формат для простого сообщения
      - "[message] &aВы успешно бросили трезубец!"
      # 2. Используем Map формат для рандомных команд
      - type: console
        target: player # (не обязательно, по дефолту player. Может быть entity, victim)
        commands:
          type: random
          random:
            - 'p give %player% 10 -s'
            - 'p give %player% 15 -s'
            - 'p give %player% 25 -s'

Все общие эффекты в данной версии:

Если target нету, значит триггер будет по дф player
- '[console] [target] [command/cmd] <cmd list>'
- '[console] [player] [command] p give %player% 10 -s'
- '[console] [player] [cmd] p give %player% 10 -s;p give %player% 15 -s;p give %player% 25 -s;p give %player% 30 -s'

- '[console] [target] [message/msg] <msg>'
- '[console] [message] Игроку %player% выпало рандомное кол-во PlayerPoints валюты'
- '[console] [msg] <white>Игроку <gold>%player%</gold> выпало рандомное кол-во PlayerPoints валюты</white>'

Если target нету, значит триггер будет по дф player
- '[actionbar] [trigger] <msg>'
- '[actionbar] &fВам выдалось рандомное кол-во PlayerPoints валюты'

Если target в этом эффекте нету, то будет по дефолту block
- '[blocks] [target] [break] <radius (Ширина;Высота;Глубина или ШиринаxВысотаxГлубина или цифра)> <drop items (true/false)> <blocks>'
- '[blocks] [break] 3;3;1 false dirt;stone;bedrock' # ломает только землю, камень и бедрок без дропа вниз
- '[blocks] [break] 3x1x3 true' # ломает все блоки кроме запрещенных с дропом вниз
- '[blocks] [break] 20' # ломает все блоки кроме запрещенных в радиусе 20x20x20 блоков

- '[blocks] [target] [place] <radius (Ширина;Высота;Глубина или ШиринаxВысотаxГлубина или цифра)> <blocks>'
- '[blocks] [place] 5;5;5 dirt;stone;bedrock' # ставит блоки в радиусе 5х5х5 в рандомном месте
- '[blocks] [place] 5x5x5 dirt' # ставит землю в радиусе 5 блоков
- '[blocks] [place] 5' # ставит рандомные блоки из вашей майнкрафт версии сервера в радиусе 5 блоков

Если target нету, значит триггер будет по дф player
- '[damage] [target] <amount (поддерживаются математические операции)> <type (только на новых версиях)>'
- '[damage] [entity] 10 magic' # выдаёт damage в 10 хп с magic типом для entity, который используется в триггере
- '[damage] 5*2/1+2-3//2' # выдаёт damage в 10 хп, только с математической операцией

Если target нету, значит триггер будет по дф radius:30
- '[disable_items] [target] <material> <time (поддерживаются математические операции)> <vanilla (false/true)'
# Запрещает использовать эндер пёрлы 10 секунд с ванильной задержкой в радиусе 30 блоков
- '[disable_items] [radius:30] minecraft:ender_pearl 10s true'
# Запрещает использовать эндер пёрлы 20 миллисекунд (тиков по другому) без ванильной задержки для жертвы от триггера
- '[disable_items] [victim] ender_pearl 10*2/1ms'

Если target нету, значит триггер будет по дф player
- '[freeze] [target] <time>'
- '[freeze] [victim] 100ms' # Замораживает жертву на 5 секунд
- '[freeze] 3*2s' # Замораживает игрока на 6 секунд

Если target нету, значит триггер будет по дф player
- '[knockback] [target] <strength> <vertical>'
- '[knockback] [victim] -3.0 0.6' # откидывает жертву по -3 силе и 0.6 вертикали
- '[knockback] -3.0*5.4' # откидывает самого игрока по -16.2 силе и 1.0 вертикали

Если target нету, значит триггер будет по дф player
- '[lightning] [target] <amount> <cooldown spawn lightning> <fire time>'
# спавнит 3 молниями раз в 3 секунды и игрок будет гореть 30 секунд + плейсхолдер %time% будет
# писать формат времени детально -> 30 секунд, 24 секунды, 21 секунда
- '[lightning] [victim] 3 3s 30s;detail'

Если target нету, значит триггер будет по дф player
- '[message] [target] <msg>'
- '[message] [player] &fВы ввели сообщение с <rainbow>поддержкой всех форматов цветов</rainbow> и всех плейсхолдеров'
- '[player] &fСообщение поддерживаются и без [message] секции'
- message: '&fСообщение можно писать и так. Если таргет нету, то будет по дф player'

Если target нету, значит триггер будет по дф player
- '[particle] [target] <name> <amount> <speed value> {data: color;to_color;size;material} {shape: type;radius;height} <x;y;z>'

Полное пояснение к данному эффекту для полного вида эффектов:

- type: particle
  target: victim
  settings:
    name: flame
    amount: 10 # есть математические операции
    speed: 0.1 # есть математические операции
    offset: '0.5;0.5;0.5' # есть математические операции
    # или
    offset: '1.5' # есть математические операции
    # или
    offsets: # есть математические операции
      x: 0.5
      y: 0.5
      z: 0.5
    # или
    offsetX: 0.5 # есть математические операции
    offsetY: 0.5 # есть математические операции
    offsetZ: 0.5 # есть математические операции
    data:
      color: "#00FF00"      # Начальный цвет (ARGB (1.19.4+)/RGB/HEX) - для DUST/REDSTONE
      to_color: "#0000FF"   # Конечный цвет - только для DUST_COLOR_TRANSITION (1.17+)
      size: 1.5               # Размер частицы (для DUST), есть математические операции
      material: DIAMOND_SWORD # Если частица ITEM_CRACK или BLOCK_CRACK
    # Специальная фигура отображения
    shape: 
      type: spiral # (point, circle, spiral, line)
      radius: 2.0  # есть математические операции
      height: 3.0  # есть математические операции

Если target нету, значит триггер будет по дф player
- '[potion] [target] [give] <potionType> <time> <level> <fall (false/true)>'
# Выдаёт игроку левитацию на 30 секунд 1 уровня и когда эффект закончится, то появится эффект плавного падения,
# который будет убирать урон от падения, также плейсхолдер %time% будет показывать время как на часах т.к.
# выбран тип clock -> 00:30, 00:05, 00:01
- '[potion] [give] minecraft:levitation 3*2*5s;clock 1 true'
# аналогично предыдущему эффекту, но тут будет урон от падения
- '[potion] [give] minecraft:levitation 3*2*5s;clock 1 false'
# будет выдавать замедление на 30 тиков 2 уровня
# тут fall не нужен, он нужен только для тех эффектов, которые будут давать урон от падения 
- '[potion] [give] slowness 30ms 2'
# данный эффект будет выдавать рандом зелье для игрока с 8 секундами. из-за математики и того что в
# самом майнкрафте нельзя выдавать эффекты с дробными числами, тут будет округляться в большую часть.
# в данном случае 15/2 = 7.5, значит округление будет в 8 секунд.
- '[potion] [give] random 15/2s'

Если target нету, значит триггер будет по дф player
- '[title] [target] "<title>\n<subtitle>" <in;stay;out>'
# пишет title сообщение для игрока с 20 45 15 временем
- '[title] "&fTitle\n&7SubTitle" 20;45;15'
# пишет title сообщение для игрока с 20 40 20 временем, т.к. само время по дф стоит 20 40 20
- '[title] "&fTitle\n&7SubTitle"'

Теперь если вы хотите выдать предметы из одной папки со всеми предметами, то это можно будет сделать с новым модулем
под названием folder, который выдаёт все предметы из данной папки, если там даже будут другие папки по типу test/new set
test/old set. Данный модуль увидит все предметы и быстро выдаст их на 1.16.5 - 1.21.11 версиях

Как это работает?
Админ пишет команду /lastitems folder <папка> [игрок] и ему выдаются все предметы из данной папки и из всех подпапок


==================================================
=   ОТКЛЮЧЕНИЕ ОПРЕДЕЛЁННЫХ МОДУЛЕЙ ИЗ ПЛАГИНА   =
==================================================


Теперь в config.yml из секции modules можно будет отключить определённые модули из плагина, если они вам не нужны при старте
или перезагрузке плагина

Как это работает?
в config.yml секция modules уже имеет все включенные модули из плагина, если хотите выключить какой-то из них
то просто ставьте вместо true -> false. Также если вам нужно выключить все модули одновременно, то просто поставьте all: true/false
как написано в комментариях


======================================
=      НОВАЯ ПОДКОМАНДА takeall      =
======================================


Теперь можно удалить все предметы из инвентаря игрока, то теперь это реализуемо в плагине

Как это работает?
Админ пишет /lastitems takeall <player> и у определённого игрока (оффлайн/онлайн) удаляются все предметы
которые написаны плагином


============================================
=     НОВАЯ РАБОТА С ФОРМАТОМ ВРЕМЕНИ      =
============================================


Теперь можно выбирать для определённого вида формата времени свои настройки, а также для эффектов
и плейсхолдеров можно будет выбирать определённый формат времени. Всё есть в time-format.yml
